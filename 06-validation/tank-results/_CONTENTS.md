# Tank results index

- `results.md`: range, resolution, adaptation, convergence, noise-recovery and immersion verdicts.
- `conditions.md`: water preparation, temperature, salinity, turbidity, target and geometry per run.
- `raw/`: all numerical run records, including the complete conditions table.
- `figures/`: range, resolution, adaptation, convergence, recovery and immersion plots.

Headline tank results: 0.8 cm range MAE, 20 mm two-target resolution,
80-to-32 kHz sediment adaptation, 0.1 dB closed-loop convergence error and
12.1 dB matched-filter output from a -7.5 dB input SNR.
