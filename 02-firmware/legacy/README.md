# Historical firmware

[esp-idf-payload/](esp-idf-payload/) preserves the replaced ESP-IDF source, its original README, binary BLE contract, figures, measurement material and release templates. Those files are retained as an unchanged snapshot of the previous design; relative links in its original README may refer to the old repository layout.

The active projects are [TX](../tx/) and [RX](../rx/). Archived build commands, pins, waveform rates, protocols and performance figures do not describe those projects. The KiCad folder also retains its original board-specific bench firmware for traceability.
