# Historical firmware

[esp-idf-payload](esp-idf-payload/README.md) retains the replaced ESP-IDF source, binary BLE contract, figures, measurement material and release templates. Implementation files remain historical; folder READMEs are maintained for navigation and to distinguish the earlier design from the active projects.

The active projects are [TX](../tx/README.md) and [RX](../rx/README.md). Each architecture has its own commands, pins, waveform profiles, protocols, and verification records. The [KiCad companion firmware](../../01-hardware/kicad/firmware/README.md) is another historical board snapshot.
