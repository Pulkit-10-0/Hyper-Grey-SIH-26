# Propagation calculations

Contains the archived sound-speed and loss calculations used by its solver.

Implementation: [physics.cpp](physics.cpp). Public declarations are in [include](include/README.md); [CMakeLists.txt](CMakeLists.txt) registers the component with ESP-IDF.

This component builds through the [archived ESP-IDF payload project](../../README.md) with its matching board configuration. The [firmware overview](../../../../../README.md) links to the active PlatformIO TX/RX projects.
