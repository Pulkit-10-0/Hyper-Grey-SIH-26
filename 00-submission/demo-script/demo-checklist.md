# SeaNergy pre-demo checklist

Complete this list during the five minutes before judging.

| ID | Time | Check | Numeric acceptance | Owner | Result |
|---|---:|---|---|---|---|
| P-01 | T-5:00 | Put ten compliance matrices and ten one-pagers on the table. | 10 + 10 copies | Documentation |  |
| P-02 | T-4:40 | Confirm laptop, phone, payload and scope power. | All four powered; battery above 70% | Hardware |  |
| P-03 | T-4:20 | Open the offline app and website. Disable venue network dependence. | 12 screens open; no network request required | Software |  |
| P-04 | T-4:00 | Confirm sensor and dial response. | Temperature valid; three dial channels change; no frozen value | Firmware |  |
| P-05 | T-3:30 | Confirm software waveforms. | CW, LFM, geometric and Barker-13 all render | DSP |  |
| P-06 | T-3:00 | Confirm window known-answer values. | -13.40, -31.47, -44.75 and -58.33 dB within 1 dB | DSP |  |
| P-07 | T-2:30 | Confirm scope trigger and saved setup. | Stable trigger; two probes; FFT preset loaded | Hardware |  |
| P-08 | T-2:00 | Fire one software ping and inspect the log. | Range, SNR, energy and provenance are finite | Software |  |
| P-09 | T-1:30 | Confirm evidence fallbacks. | Eight evidence cards and four offline captures open | Documentation |  |
| P-10 | T-1:00 | Confirm hardware safety. | Current limit set; amplifier muted before reconnection | Hardware |  |
| P-11 | T-0:30 | Put the payload in its start state. | Coastal preset; LFM; Hamming; 10 s interval | Demo lead |  |
| P-12 | T-0:10 | Start the six-minute timer. | Timer visible to secondary operator | Secondary operator |  |

Stop the demonstration if wiring overheats, the driver oscillates, or the current limit trips twice.
