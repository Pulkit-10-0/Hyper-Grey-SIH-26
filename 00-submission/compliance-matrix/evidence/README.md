# Compliance evidence cards

Start with [EVIDENCE_INDEX.md](EVIDENCE_INDEX.md), which records each card's provenance. Eight PNG cards cover the physical module, DMA throughput, waveform modes, sensor interface, adaptation, filtering/windows, output validation and power/endurance.

The cards bring together software evidence, modelled results, and engineering targets, labelled by source. Follow the [validation dossier](../../../06-validation/README.md) and [compliance matrix](../README.md) for the supporting records.

Preserve C-01 through C-08 filenames unless the workbook and index are updated together.
