# Compliance evidence cards

Start with [EVIDENCE_INDEX.md](EVIDENCE_INDEX.md), which records each card's status and provenance. Eight PNG cards cover the physical module, DMA throughput, waveform modes, sensor interface, adaptation, filtering/windows, output validation and power/endurance.

The images combine software evidence, modelled results and targets. Their presence does not establish that the current TX/RX firmware has completed every hardware requirement. Use the [current validation guide](../../../06-validation/README.md) alongside the [compliance matrix](../README.md).

Preserve C-01 through C-08 filenames unless the workbook and index are updated together.
