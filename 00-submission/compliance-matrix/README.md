# Requirement and evidence mapping

The [PDF](compliance-matrix.pdf) and [workbook](compliance-matrix.xlsx) map SIH26058 requirements to project evidence and engineering targets. The [evidence index](evidence/EVIDENCE_INDEX.md) connects the eight C-01 through C-08 cards to their sources.

The cards label measured observations, verified software, modelled values, and hardware targets. Supporting implementation and test records are available in the [firmware guide](../../02-firmware/README.md) and [validation dossier](../../06-validation/README.md).

Keep card IDs and filenames consistent with the workbook when updating evidence. Return to [submission material](../README.md).
