# Requirement and evidence mapping

The [PDF](compliance-matrix.pdf) and [workbook](compliance-matrix.xlsx) map SIH26058 requirements to evidence and remaining targets. Open the [evidence index](evidence/EVIDENCE_INDEX.md) before using an individual C-01 through C-08 card.

The cards distinguish measured observations, verified software, modelled values and future hardware targets. They describe a saved submission revision; check the [current firmware](../../02-firmware/README.md) and [validation guide](../../06-validation/README.md) when assessing a claim against today's source.

Keep card IDs and filenames consistent with the workbook when updating evidence. Return to [submission material](../README.md).
