# Risks and demonstration contingencies

The [risk workbook](risk-register.xlsx) records project risks; [contingency.md](contingency.md) assigns demonstration fallback actions and owners. The `.inspect.ndjson` file is a saved workbook-inspection artifact.

Use the [hardware](../../01-hardware/README.md), [TX/RX firmware](../../02-firmware/README.md), and [app](../../04-software/README.md) guides to match the contingency actions to a session. Available demonstration paths include app Simulation mode, saved photographs/videos, and independent TX/RX tools.
