# Risks and demonstration contingencies

The [risk workbook](risk-register.xlsx) records project risks; [contingency.md](contingency.md) assigns demonstration fallback actions and owners. The `.inspect.ndjson` file is a saved workbook-inspection artifact.

Review risks against the actual [hardware](../../01-hardware/README.md), [TX/RX firmware](../../02-firmware/README.md), and [app](../../04-software/README.md) before a session. The contingency plan contains older replay and integration assumptions. The current app's Simulation mode, saved images/videos, and independent firmware tools are distinct fallback paths; a described recovery target does not establish that it has been rehearsed.
