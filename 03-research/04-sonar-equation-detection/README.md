# 04-sonar-equation-detection

## What this folder supports

The active sonar equation, detection threshold, and reverberation as the competing term.

## Where it is used in our work

`echoSnrDb()`, `transmissionLossDb()`, `maxDetectionRange()`, and the detection threshold in the solver.

## Note

These papers cover active sonar detection performance, reverberation suppression and the signal-to-noise framing our solver optimises against.
