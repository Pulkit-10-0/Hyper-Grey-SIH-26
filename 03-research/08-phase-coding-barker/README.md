# 08-phase-coding-barker

## What this folder supports

Barker-13, its 22.3 dB peak-to-sidelobe ratio, and constant-envelope phase coding.

## Where it is used in our work

`BARKER_13` and the 'barker13' synthesis mode; the coded-pulse mode in the solver.

## Note

Includes number-theoretic work on Barker sequences, which is what establishes that no longer binary Barker sequence is known - the reason 13 is the practical limit.
