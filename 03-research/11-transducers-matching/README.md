# 11-transducers-matching

## What this folder supports

Transducer resonance, clamped capacitance, and the series matching network.

## Where it is used in our work

The matching network in the analog front end; the impedance sweep in `01-hardware/bench-setup`.

## Note

A piezo transducer is a capacitor with a sharp mechanical resonance. These papers establish the equivalent-circuit model and the impedance-matching design that gets power into it.
