# 09-adaptive-cognitive-sonar

## What this folder supports

The core claim: adapting the transmitted waveform to the measured environment, in a closed loop.

## Where it is used in our work

`decide()`, `requiredMarginDb()`, the noise-correction feedback in `engine.ts`; the whole product thesis.

## Note

The most important folder in this tree. Cognitive radar and adaptive sonar share the framing: measure the channel, choose the waveform, measure the result, correct.
