# Commercial model figures

[make_figures.py](../make_figures.py) generates these figures for the [cost and market paper](../README.md):

- [Evaluation-unit COGS](cogs.png) and [margin sensitivity](margin-sensitivity.png).
- [SAM segments](sam-segments.png), [SOM ramp](som-ramp.png), and [TAM/FX sensitivity](tam-fx.png).

These charts visualize the paper's dated planning assumptions and commercial scenarios. Regenerate them from the underlying model when revising inputs, and keep the associated source notes with the figures.
