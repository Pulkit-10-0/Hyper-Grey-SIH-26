# Technical-report figures

[Project overview](../../../README.md) · [Parent folder](../README.md)

Architecture, physics/DSP, model-evaluation, and validation figures retained for the technical report. The firmware architecture/state/timing graphics describe the archived ESP-IDF design. T-series result figures inherit the final-configuration engineering-projection basis.

See the [report guide](../README.md), [numerical study](../../../05-models/README.md), and [validation dossier](../../../06-validation/README.md) for provenance. Five validation figures are regenerated by the parent `make-figures.py` script from dossier CSVs; regeneration does not turn projections into measurements.
