# Interface examples

[Project overview](../../../README.md) · [Parent folder](../README.md)

Worked examples for the API documents. Binary BLE examples belong to the archived firmware contract; NDJSON examples illustrate the console-side protocol expected by the app. They do not add protocol support to current TX/RX firmware.

Read the [API guide](../README.md) first and compare examples with the [current app core](../../../04-software/mobile-android/src/core/) before use.
