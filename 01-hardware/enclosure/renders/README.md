# Enclosure design views

These rendered design views show the V1 mesh and V2 enclosure concept, including exterior geometry, package proportions and assembly relationships.

- [V2 product view](housing-v2-product-render.png) and [V2 exploded view](housing-v2-exploded-render.png): sealed-housing concept and assembly.
- `housing-01-three-quarter.png` through `housing-07-height-field.png`: exterior, underside and mesh inspection views.
- [housing-ortho.png](housing-ortho.png): orthographic reference.

For geometry and source-file details, read the [CAD guide](../cad/README.md). The [enclosure guide](../README.md) links seal design, fit and test plans.
