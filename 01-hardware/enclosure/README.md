# Enclosure and mechanical integration

This folder separates the supplied physical-form mesh from the proposed sealed enclosure design. A printed shell demonstrates fabrication and form; it does not establish water tightness or a depth rating.

- [CAD files and release status](cad/README.md): V1 STL mesh and V2 parametric OpenSCAD model.
- [Renders](renders/README.md): exterior, mesh and exploded design views.
- [Hull-section fit envelope](hull-section/README.md): installation clearances and printable outline.
- [Drawings](drawings.pdf): mechanical reference.
- [Print settings](print-settings.md): fabrication guidance.
- [Seal design](seal-design.md): proposed O-ring geometry and design holds.
- [Dunk and pressure test](dunk-test.md): planned acceptance procedure; **not performed**.

V1 is an open mesh and is not a closed pressure solid. V2 still needs native solid review, penetrator definition and verified fabrication exports before pressure testing. The compact PCB is 100 × 100 mm; its external modules, wire bends and mounting support also need physical fit checks.
