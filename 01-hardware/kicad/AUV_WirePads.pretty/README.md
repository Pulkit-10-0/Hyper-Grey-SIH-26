# AUV wire-pad footprints

Project-specific KiCad footprints for one through eight labelled wire connections. Each `WirePads_1xNN.kicad_mod` provides the corresponding pad count; the compact PCB uses these for external module wiring rather than assuming a module's physical pin order.

The library is registered in the [parent KiCad project](../README.md). It is separate from the copied upstream [standard footprint collection](../libraries/README.md). Confirm functional terminal labels using the [assembly wiring guide](../../assembly/README.md); a footprint name alone does not identify a module terminal.
