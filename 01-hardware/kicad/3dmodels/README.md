# Packaged 3D component models

Selected KiCad package models are included locally so the PCB preview opens without machine-specific library paths. STEP and VRML pairs retain the original package-library folder structure; some are generic package representations rather than exact purchased modules.

- [NOTICE.md](NOTICE.md): origin and unchanged-copy policy.
- [LICENSES.md](LICENSES.md): per-model attribution and license notices.
- [LICENSE_KiCad_Libraries.md](LICENSE_KiCad_Libraries.md): library exception and licensing context.
- [Model path map](../libraries/model_path_map.json): source-to-project paths.

The individual model headers take precedence over collection summaries. Keep the model files and license notices together when redistributing. The [parent project guide](../README.md) describes the design and its checked model references.
