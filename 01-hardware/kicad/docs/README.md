# Native project documentation exports

This is the documentation packaged alongside the compact Rev B KiCad project.

- [Assembly_and_Wiring.md](Assembly_and_Wiring.md) / [HTML](Assembly_and_Wiring.html): current board assembly and module wiring.
- [BOM_purchase.csv](BOM_purchase.csv) and [BOM_by_reference.csv](BOM_by_reference.csv): purchase and reference tables.
- [Existing_Modules.csv](Existing_Modules.csv): reused external modules.
- [Connector_Wiring.csv](Connector_Wiring.csv) and [Every_Component_Pin.csv](Every_Component_Pin.csv): connector/pin mapping.
- [documentation_check.json](documentation_check.json): stored documentation consistency check.

Equivalent review copies appear under [hardware assembly](../../assembly/README.md) and [BOM](../../bom/README.md). Preserve revision consistency if regenerating either copy. See the [project guide](../README.md) for source files and hardware status.
