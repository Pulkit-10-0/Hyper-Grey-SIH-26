# Historical companion sketch

[main.cpp](main.cpp) is the PCB companion source: ESP32-S3 I/O, ADS1115/OLED handling, continuous 40 kHz TX and the audible test path. TDS and turbidity voltage reporting compensates the PCB's 2:1 dividers.

This file belongs to the [retained historical PlatformIO project](../README.md). Its divider change and original-source hashes are documented in the [parent firmware guide](../../README.md). Follow the current firmware links there for active build and wiring instructions.
