# Local KiCad footprint libraries

This is the selected standard footprint collection packaged with Compact Rev B. The only documented changes to copied footprints replace their model URI prefix with `${KIPRJMOD}/3dmodels/`; package geometry is retained.

- [NOTICE.md](NOTICE.md): upstream origin, modifications and attribution.
- [library_manifest.json](library_manifest.json): filenames and recorded hashes.
- [model_path_map.json](model_path_map.json): packaged model paths.
- [license_sources.json](license_sources.json): licensing source references.
- [LICENSE_KiCad_Libraries.md](LICENSE_KiCad_Libraries.md), [CC-BY-SA-4.0.txt](CC-BY-SA-4.0.txt), [GPL-3.0-or-later.txt](GPL-3.0-or-later.txt): preserved terms and exceptions.

Retain the original notices when distributing these files. The custom [AUV wire pads](../AUV_WirePads.pretty/README.md) are a separate project library. See the [KiCad guide](../README.md) for opening the native project with these paths intact.
