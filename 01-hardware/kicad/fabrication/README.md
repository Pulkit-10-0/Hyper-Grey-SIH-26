# Compact Rev B fabrication exports

Gerbers, plated/non-plated Excellon drills, drill maps and the Gerber job file were exported from the checked 100 × 100 mm, two-layer Rev B board. These are the loose files packaged with the KiCad project.

Read [Manufacturing_Notes.md](Manufacturing_Notes.md) for material, hole, mounting and outline interpretation. For a manufacturing submission, use the [complete current Gerber ZIP](../../pcb/gerbers/AUV_V3_RevB_Compact_Gerbers.zip); it includes the matching drills. The independent [verification record](../verification/README.md) and release hashes identify the design snapshot.

After changing the native board, rerun its design checks and regenerate the entire export set; keep the files from each revision together. Return to the [KiCad guide](../README.md).
