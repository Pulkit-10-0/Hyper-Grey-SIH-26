This folder preserves the earlier layout study, architectural schematic and four-layer target stack-up. The [stackup.md](stackup.md) document describes the historical parallel-converter concept; current Compact Rev B uses its own two-layer release.

- [seanergy.kicad_pcb](seanergy.kicad_pcb) and [seanergy.kicad_pro](seanergy.kicad_pro): historical source.
- [layout-notes.md](layout-notes.md), [pick-and-place.csv](pick-and-place.csv): retained layout/planning records.
- [drc-report.txt](drc-report.txt), [fab-order.txt](fab-order.txt): historical check and release-status records.
- [gerbers/](gerbers/README.md), [drill/](drill/README.md): mechanical previews only.
