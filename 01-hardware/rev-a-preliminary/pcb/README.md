# Preliminary Rev A board archive

This folder preserves the earlier layout study and proposed stack-up. Its schematic was a logical container, ERC/DRC were not run, and the board was not ordered. The four-layer target in [stackup.md](stackup.md) belongs to the proposed parallel-converter architecture; it is not the compact board's stack.

- [seanergy.kicad_pcb](seanergy.kicad_pcb) and [seanergy.kicad_pro](seanergy.kicad_pro): historical source.
- [layout-notes.md](layout-notes.md), [pick-and-place.csv](pick-and-place.csv): retained layout/planning records.
- [drc-report.txt](drc-report.txt), [fab-order.txt](fab-order.txt): explicit not-run/hold status.
- [gerbers/](gerbers/README.md), [drill/](drill/README.md): mechanical previews only.

**Not for fabrication.** Read the [Rev A archive guide](../README.md); current manufacture files are in [Compact Rev B PCB](../../pcb/README.md).
