# Bench and tank setup plans

This folder describes the planned characterisation rig, instrument settings and tank arrangement. The local documents call for recorded instrument identities, firmware hashes, conditions and raw data before accepting a result.

- [bench-setup.md](bench-setup.md): rig definition and reproducibility record.
- [instrument-settings.md](instrument-settings.md): planned measurement settings.
- [transducer-characterisation.md](transducer-characterisation.md): characterisation procedure.
- [water-tank.md](water-tank.md): tank geometry and environmental controls.
- [photos/](photos/README.md): setup renders and diagrams, with a provenance register.

The plans include the proposed wideband payload, current monitor and bridge/transformer equipment. They are not an as-built wiring guide for the 40 kHz module bench or the unbuilt Rev B PCB. For Rev B wiring, use [assembly and wiring](../assembly/README.md). Actual project bench photos are under [08-media/photos](../../08-media/photos/).
