# Bench and tank setup documentation

The completed setup documentation defines the characterisation rig, instrument settings and tank arrangement, including instrument identities, firmware hashes, test conditions and raw-data records for reproducible measurements.

- [bench-setup.md](bench-setup.md): rig definition and reproducibility record.
- [instrument-settings.md](instrument-settings.md): measurement configuration reference.
- [transducer-characterisation.md](transducer-characterisation.md): characterisation procedure.
- [water-tank.md](water-tank.md): tank geometry and environmental controls.
- [photos/](photos/README.md): setup renders and diagrams, with a provenance register.

The procedures cover the wideband payload concept, current monitor and bridge/transformer equipment. For Compact Rev B module connections, use [assembly and wiring](../assembly/README.md). Project bench photographs are under [08-media/photos](../../08-media/photos/).
