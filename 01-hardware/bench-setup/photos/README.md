# Bench setup visuals

These are engineering setup illustrations and diagrams for the planned bench and tank procedures. The filenames ending in `-render.png` are renders; the `.jpg` files are deterministic diagrams, despite the folder name.

- [PHOTO_REGISTER.md](PHOTO_REGISTER.md): content and evidence status of each image.
- [bench-layout-render.png](bench-layout-render.png): proposed dry-bench arrangement.
- [tank-layout-render.png](tank-layout-render.png): proposed tank arrangement.
- [transducer-characterisation-render.png](transducer-characterisation-render.png): characterisation setup illustration.
- [bench-layout.jpg](bench-layout.jpg), [tank-layout.jpg](tank-layout.jpg), [instrument-chain.jpg](instrument-chain.jpg): technical diagrams.

Return to the [bench setup guide](../README.md). These visuals alone do not establish that a measurement or tank test was performed.
