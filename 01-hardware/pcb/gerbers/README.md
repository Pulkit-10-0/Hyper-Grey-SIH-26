# Compact Rev B Gerbers

Use [AUV_V3_RevB_Compact_Gerbers.zip](AUV_V3_RevB_Compact_Gerbers.zip) for the complete release package, including matching plated/non-plated drills. The loose Gerbers and `.gbrjob` beside it support layer inspection.

The board outline is **100.00 × 100.00 mm**, with two copper layers and four non-plated mounting holes. Other mask, paste, silkscreen and outline files are not additional copper layers. Confirm the cut-path centreline in the fabricator's viewer; an outline-stroke bounding box can read 100.05 mm.

Read [manufacturing-notes.md](../manufacturing-notes.md) and the [verification summary](../../verification-summary.md) before ordering. These exports are for an unbuilt prototype design. Never mix them with the [preliminary Rev A mechanical previews](../../rev-a-preliminary/README.md). Return to the [PCB guide](../README.md).
