# Compact Rev B drill exports

- [AUV_V3_Combined-PTH.drl](AUV_V3_Combined-PTH.drl): plated component holes and vias.
- [AUV_V3_Combined-NPTH.drl](AUV_V3_Combined-NPTH.drl): non-plated mounting holes.
- [PTH map](AUV_V3_Combined-PTH-drl_map.svg) and [NPTH map](AUV_V3_Combined-NPTH-drl_map.svg): drill-reference drawings.

Use these only with the matching Rev B Gerbers. The [complete fabrication ZIP](../gerbers/AUV_V3_RevB_Compact_Gerbers.zip) already contains the matching drill files. Do not scale, mirror, offset or merge the two drill classes. Read the [PCB manufacturing guide](../README.md) before submitting a package.
