# Fabrication preview status

This folder now contains deterministic layer-stack and drill-map images plus real RS-274X mechanical/silkscreen preview files. The drill folder contains an Excellon preview and dimensioned drill map.

These files are for design communication and independent viewer practice. They are not the final routed copper set, have not passed DRC, and have not been sent to a fabricator. The preview ZIP is deliberately named `mechanical-preview` so it cannot be mistaken for a production release.
