# Compact Rev B schematic exports

- [schematic.pdf](schematic.pdf): seven-sheet native schematic export for the current board.
- [netlist.xml](netlist.xml): connectivity export.
- [erc-report.json](erc-report.json) and [erc-report.txt](erc-report.txt): stored electrical-rule-check results.

The editable schematic source and local libraries are in the [KiCad project](../kicad/README.md). The [verification summary](../verification-summary.md) records zero ERC violations for this design release. Use [assembly and wiring](../assembly/README.md) to connect external modules by functional terminal, and regenerate all exports after native design changes.
