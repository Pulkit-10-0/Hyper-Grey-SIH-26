# Assembly illustrations

These images support the assembly documentation. They include rendered setup views and technical illustrations; they are not photographs of an assembled Compact Rev B PCB.

- [PHOTO_REGISTER.md](PHOTO_REGISTER.md) identifies each visual and the build photograph still required for that stage.
- [assembly-soldering-render.png](assembly-soldering-render.png) and [power-bringup-render.png](power-bringup-render.png) are illustrative renders.
- `step-01.jpg` through `step-08.jpg` are retained assembly-stage illustrations. Use their register entries to interpret them.

See the [current assembly guide](../README.md) before using any depicted procedure. Some illustration stages refer to the earlier proposed wideband architecture rather than the compact board.
