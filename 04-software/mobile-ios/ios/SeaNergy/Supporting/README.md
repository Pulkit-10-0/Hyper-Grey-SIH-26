# Expo native runtime properties

[Expo.plist](Expo.plist) contains Expo runtime/update configuration embedded by the native application. Keep it aligned with [app.json](../../../app.json), Expo generation and the corresponding [Info.plist](../Info.plist).

This file is configuration rather than a telemetry endpoint or measurement record. Follow the [native build guide](../../README.md) when changing and verifying the iOS bundle.
