# Application artwork

The PNG files here are the icon, splash artwork, Android adaptive-icon layers and web favicon referenced by [app.json](../app.json). This folder is application branding; it does not contain measured sonar data.

Change platform artwork and its `app.json` references together, then regenerate native resources when required. The Android native `res/` directories and iOS asset catalogs have format-specific rules and are documented from their native project READMEs rather than receiving Markdown files inside each resource folder.
