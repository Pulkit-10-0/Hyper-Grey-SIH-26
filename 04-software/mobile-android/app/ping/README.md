# Ping detail route

[[id].tsx](%5Bid%5D.tsx) displays one ping selected from the session history. Its identifier comes from navigation, while record contents come from the [engine](../../src/core/engine.ts).

Open this route through the Log screen rather than inventing a record identifier. Retain the record's simulation/telemetry provenance when displaying or exporting its values. See the [route guide](../README.md) for the rest of the console.
