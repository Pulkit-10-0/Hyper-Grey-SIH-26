# SeaNergy engineering website

An offline engineering dossier built with static HTML, CSS and JavaScript. It
includes locally rendered charts, responsive layouts and print styling.

## Run it

Open [index.html](index.html) directly, including from a USB drive:

```sh
open index.html
```

To serve the same page over HTTP:

```sh
python -m http.server 8000
```

## Shared numerical data

`assets/data.js` is generated by the application's numerical core. Regenerate
it from the app project when the underlying model changes:

```sh
cd ../mobile-android
npm run verify
node scripts/site-data.mjs > ../website/assets/data.js
```

The generator computes the absorption and sound-speed curves, turbidity sweep,
resolution table, window sidelobes and modelled energy split using the same
TypeScript modules as the handset. The dossier's prose and hardware selections
are maintained alongside that generated snapshot. The [firmware guide](../../02-firmware/README.md)
and [hardware guide](../../01-hardware/README.md) provide the current component
and interface references.

## Design features

| Feature | Implementation |
|---|---|
| Offline operation | Local assets and a system font stack |
| Compact charts | A small SVG renderer using the generated model data |
| Direct opening | Static files work from a local folder or an HTTP host |
| Print layout | Black-on-white styling and section-aware page breaks |
| Phone layout | Single column below 700 px with scrollable tables |

## Verification

From this folder:

```sh
node verify.js
```

The verifier renders the page in jsdom and checks script execution, five charts,
three populated tables, navigation anchors, relative links and expected model
trends. It also checks markup, styles and scripts for external dependencies to
preserve offline operation.

`verify.js` uses jsdom from `../mobile-android/node_modules`. Run `npm ci` in the
Android app first, or pass another dependency directory:

```sh
node verify.js path/to/node_modules
```

After content or layout changes, run the verifier and inspect the page at phone
width and in print preview. The [release build record](../releases/BUILDS.md)
preserves the app's recorded software-check results.
